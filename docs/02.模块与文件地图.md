# 02. 模块与文件地图

## core（118 个 Kotlin 文件）

### gateway/ —— 网关主体（17 个文件）

| 文件 | 职责 |
|---|---|
| `GatewayEngine.kt` | 引擎门面：路由解析、账号管理、额度刷新、任务、导入导出、模型目录 |
| `GatewayHttpServer.kt` | NanoHTTPD 层：解析请求、鉴权、选号循环、流式转发、写调用记录 |
| `GatewaySettings.kt` | 所有设置数据结构（含 `CustomProviderConfig`）与 JSON 往返 |
| `ProviderProtocols.kt` | 自定义供应商的上游协议表（路径、鉴权、请求体形状、是否强制流式） |
| `ApiEndpoints.kt`（在 provider/） | 对外暴露的端点目录（对话 + 全部透传端点） |
| `GatewayErrorMapping.kt` | 把所有失败分类映射成对客户端成立的状态码与错误码 |
| `ModelExposureSettings.kt` | 模型开放名单 |
| `ModelCatalogChanges.kt` | 两轮模型目录的新增 / 移除对比（只比较本轮真拉到目录的供应商） |
| `AutoCheckinSettings.kt` | 自动签到偏好（两个触发开关默认关 + 时刻 + 抖动） |
| `AutoCheckinPlan.kt` | 自动签到的纯时间计算：本地日期、抖动、下一次目标时刻 |
| `ActiveRequests.kt` | 在途请求表（只用于展示，不参与调度） |
| `NoticeEvents.kt` | 系统吐司总线（8 种类型，2 分钟去重） |
| `QuotaAlerts.kt` | 强提醒（横幅 + 震动 + 常驻通知） |
| `BalancePresets.kt` | 余额查询预设（New API / DeepSeek / Kimi / 智谱 …） |
| `ProxySettings.kt` | HTTP / SOCKS5 代理配置 |
| `OpenAiApi.kt` | 对外 OpenAI 兼容响应的拼装工具 |
| `ProviderBootstrap.kt` | 供应商注册表初始化 |
| `LoopbackCallbackServer.kt` | 浏览器登录的本地回调端口 |

### provider/ —— 供应商协议（69 个文件，9 个子包）

| 子包 | 供应商 | 说明 |
|---|---|---|
| `trae/` | 字节 | SOLO 私有通道，协议转换最重 |
| `codebuddy/` | 腾讯 | 强制流式，成长任务 |
| `antigravity/` | 谷歌 | Gemini 风格协议，凭证策略有铁律 |
| `loomy/` | 讯飞 | HTTP 200 + 业务码，新手任务 |
| `raccoon/` | 商汤 | 响应包在 `data` 里 |
| `mcloud/` | 灵犀 | 加密请求体（AES-CBC），token 账本 |
| `chatgpt/` | ChatGPT | Responses API 转换 |
| `custom/` | 自定义 | 用户填 Base URL + Key，走协议表 |
| `cline/` | Cline | 免费池 / 订阅池共用一份凭证，池靠模型 id 前缀区分 |

顶层公共文件：

| 文件 | 职责 |
|---|---|
| `Provider.kt` | 供应商接口（`openChat` / `passthrough` / `taskList` / `performAction` …） |
| `ProviderModels.kt` | `ProviderModel`（含端点识别）、任务、额度包等数据模型 |
| `ApiEndpoints.kt` | 端点目录（对话 / 生图 / 语音 / 向量 / 重排 / 审核 / 视频 / 模型列表） |
| `ChatCall.kt` | 统一的调用返回类型（流式 / 聚合 / 失败） |
| `StreamSupport.kt` | `LineTransformStream`：逐行转换流（Responses 事件转 Chat chunk 用它） |
| `UpstreamError.kt` | 错误分类枚举 |
| `ProviderRegistry.kt` | providerId → Provider 实例 |

### failover/ —— 容错（9 个文件）

| 文件 | 职责 |
|---|---|
| `FailoverConfig.kt` | 所有容错参数（重试、熔断、冷却、禁用、并发、跨区域、跨供应商） |
| `ModelCooldownTracker.kt` | 模型级冷却（供应商 + 账号 + 模型，10 分钟，不落盘） |
| `ModelBanTracker.kt` | 模型禁用（供应商 + 模型，默认 24 小时，**落盘**） |
| `ProviderCircuitBreaker.kt` | 供应商级熔断 |
| `ConcurrencyGate.kt` | 并发闸门（单账号 / 全局在途上限） |
| `CrossProviderFailover.kt` | 跨供应商候选（默认关闭） |
| `CrossProviderSwitchDecider.kt` | 跨供应商切换判定 |
| `FailoverDecision.kt` | 失败后的动作决策（换号 / 冷却 / 放弃） |
| `ProviderMetricsTracker.kt` | 供应商指标（成功率、延迟） |

### pool/ —— 账号池（3 个文件）

| 文件 | 职责 |
|---|---|
| `AccountPool.kt` | 账号凭证、额度、启用状态、优先级、自定义名、选号 |
| `AccountTransfer.kt` | 导入导出的信封编解码（v4） |
| `AccountTransferCodec.kt` | `.agw` 二进制 + AES-256-GCM |

### 其它

| 目录 | 内容 |
|---|---|
| `usage/` | 调用记录、日志环形缓冲、用量统计、存储占用 |
| `security/` | system 提示词脱敏、出网取证、风控设置 |
| `update/` | 应用更新检查、APK 下载、镜像测速 |
| `store/` | `KeyValueStore` 抽象（Android 用加密实现，CLI 用内存/文件） |
| `util/` | HTTP 工具、JSON 工具、网络错误翻译、数字格式化 |
| `protocol/` | 底层协议工具 |

## app（58 个 Kotlin 文件）

### ui/ —— 页面（46 个文件）

| 文件 | 页面 |
|---|---|
| `HomeScreen.kt` | 首页（状态、额度、调度拓扑、日志） |
| `ProviderListScreen.kt` | 供应商列表 |
| `ProviderDetailScreen.kt` | 供应商详情（登录 + 账号 + 专属设置） |
| `CustomProviderScreen.kt` | 自定义供应商表单（**新建与编辑共用这一个**） |
| `ModelsScreen.kt` | 模型目录与测试 |
| `LogsScreen.kt` | 调用记录与运行日志 |
| `TaskCenterScreen.kt` | 任务中心（批量签到 / 任务 / 额度） |
| `ResilienceScreen.kt` | 并发与容错（含模型禁用时长） |
| `ApiSettingsScreen.kt` | 接入设置 |
| `AccountTransferScreen.kt` | 账号导入导出 |
| `AccountComponents.kt` | 账号卡片公共组件（标题、优先级、开关、改名） |
| `AppDialog.kt` | **全应用唯一**的弹窗外观 |
| `AppNavBar.kt` | 底部导航栏 |

`ui/providers/` 下每家供应商一个子包，实现 `ProviderUi`（图标、登录入口、账号附加信息）。

### service/ —— 前台服务（6 个文件）

| 文件 | 职责 |
|---|---|
| `GatewayService.kt` | 前台服务保活，网关随服务启停 |
| `LiveStatusNotifier.kt` | 实时状态通知（有请求在途时显示） |
| `GatewayNoticeNotifier.kt` | 系统吐司接收 |
| `QuotaAlertNotifier.kt` | 额度告警横幅 + 震动 |
| `GatewayTileService.kt` | 控制中心磁贴 |
| `FloatingKeepAlive.kt` | 悬浮窗保活 |

### data/ —— 本地数据（4 个文件）

| 文件 | 职责 |
|---|---|
| `EncryptedKeyValueStore.kt` | Keystore 加密存储 |
| `KeepAlive.kt` | 保活偏好与状态 |
| `ApkInstaller.kt` | 应用内更新安装 |
| `LanAddresses.kt` | 局域网地址枚举 |
